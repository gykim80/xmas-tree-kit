# Promo storyboard (v2)

1080×1920, 30 fps, 120 BPM, 68 beats (34 s). The look follows the "Santa's Shop" landing page:
crimson hero with darker pine silhouettes, a white brush-script "Christmas" behind the tree,
serif headlines, rounded product cards, pill buttons and faint swirls on the white sections.

The soundtrack is the "Jingle Bells" chorus (public domain) on bells over a four-on-the-floor beat.
The melody starts on the drop at beat 4 and ends on the final C at beat 64.

| Beats | Time | Scene | Picture | Copy |
|---|---|---|---|---|
| 0–3 | 0.0–2.0 s | Hero, build | Red page, nav bar, two forest layers rise. "Christmas" is written left to right | A procedural tree for / Christmas |
| 4–9 | 2.0–5.0 s | Hero, drop | Flash. The tree shoots up through the script word behind a gold scan ring | Grown from one seed. |
| 10–21 | 5.0–11.0 s | Seeds | Wipe to the white page. A red card holds a bare fir; a new seed every beat, then every half beat | One seed, one tree. / #0412 / seed · spread · droop |
| 22–29 | 11.0–15.0 s | Presets | Product carousel. A grey card slides in from the right on every beat with the next preset | Pick a preset. / classic … bare |
| 30–37 | 15.0–19.0 s | Hang | Back to red. Three ornaments land on every half beat, a script counter counts them | Hang your own ornaments. / ×48 / tree.addOrnament(…) |
| 38–45 | 19.0–23.0 s | Checklist | White page. Tree in a red card, four rows get ticked: lights, garland, star, snow | Finish the decorating checklist |
| 46–57 | 23.0–29.0 s | Ship | Red page, the cozy tree up top, code cards stack from the bottom | Drop it anywhere / web page · three.js · engines · install |
| 58–67 | 29.0–34.0 s | Outro | The full hero again with the dressed tree, a GitHub pill and the licence | Grow your own tree / github.com/gykim80/xmas-tree-kit |

Every scene change gets a whip wipe in the next page colour, a short white flash, a camera punch-in and a sub-boom in the music.

Render with `npm run promo` (needs ffmpeg). Preview in real time at `/promo/` on the dev server.
